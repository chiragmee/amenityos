# 18 — Roadmap

## Phase 1 — MVP

- text booking
- free bookings
- paid bookings with credits
- deterministic booking engine
- tool calling
- policy RAG
- QR access
- simulated IoT validation
- voice input
- browser TTS
- evaluation suite
- observability

## Phase 2 — Production-quality interaction

- realtime voice
- interruption handling
- VAD
- streaming STT/TTS
- better ambiguity resolution
- richer calendar integrations
- notification service

## Phase 3 — Enterprise readiness

- SSO
- tenant isolation
- role-based admin controls
- audit/compliance features
- production access-control integrations
- real payment/credit management
- enterprise notification channels

## Phase 4 — Intelligent workplace assistant

Potential capabilities:
- proactive reminders
- calendar-aware room suggestions
- recurring booking assistance
- preference-aware ranking
- navigation to amenities
- occupancy insights
- facility issue reporting

## Architectural principle for future phases

New intelligence should not weaken the source-of-truth boundaries.

Adding a stronger model should improve interpretation and orchestration, not replace deterministic authorization and transaction controls.
